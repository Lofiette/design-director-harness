# SIM · журнал улучшений DDH 6.0

SIM хранит историю попыток улучшить правило. В версии 6.0 журнал принимает синтетические примеры. Мастер-журнал пользователя ведётся в Notion. Для локальной работы не нужны учётные данные, сетевой адаптер или перенос частных записей.

## Подключение к проекту

Распакуйте полный ZIP релиза DDH 6.0 и выполните команду из его корня. Если зависимости базового установщика ещё не доступны в окружении Python, используйте окружение, указанное в [инструкции DDH](../README.md#установить-и-обновить).

```powershell
node tools/ddh.mjs install --project ./example --modules sim
node tools/ddh.mjs sim --project ./example index
```

Папка проекта должна уже существовать. Для существующей установки используйте `update --project ./example --modules sim`. При обновлении без `--modules` DDH сохраняет текущий выбор. `update --project ./example --modules none` отключает команды модуля и сохраняет события. Чистая установка без флага содержит пять обычных навыков.

DDH запускает проверенный по установочной квитанции адаптер из проекта. При необходимости передайте `--python ПУТЬ` до имени операции. Хранилище Continuous Memory по умолчанию находится в `<проект>/.cpt/continuous-memory`. Чтобы использовать имеющийся экземпляр памяти, передайте `--store ПУТЬ` после имени операции. Индекс строится из неизменяемых записей, поэтому его можно собрать заново в любой момент.

## Запись и поиск

```powershell
node tools/ddh.mjs sim --project ./example record --input evaluation/sim-001/native-source/arm-1.json
node tools/ddh.mjs sim --project ./example record --input evaluation/sim-001/native-source/arm-2.json
node tools/ddh.mjs sim --project ./example index --stage context_handoff --failure-type state_update_scope
node tools/ddh.mjs sim --project ./example attempts --problem SIM-001 --model gpt-6.2-astra --limit 2
node tools/ddh.mjs sim --project ./example evidence --problem SIM-001 --attempt work-0a6061ff2fbf7e009e640487
```

`index` возвращает дерево «этап → тип сбоя → проблема» и короткие карточки с последней успешной попыткой в выбранной среде, если она была. `attempts` раскрывает от одной до трёх последних подходящих попыток, включая неудачные. `evidence` открывает точную запись и исходное свидетельство. К этапу и типу сбоя можно добавить фильтры `--project-name`, `--harness`, `--model`, `--version` и `--status`. Результат другой среды доступен только с её метаданными.

Полный пример формата `ddh-sim-attempt/1` есть в [сохранённой попытке](../evaluation/sim-001/native-source/arm-2.json). Один критерий успеха получает один канонический `problem.id` и стабильный `criterion_key`. Независимые критерии получают разные ID, даже если встречаются в одном прогоне. `related` связывает проблемы в обе стороны. Новое измерение получает отдельный `attempt_id`. Повтор той же записи возвращает `duplicate`, изменение под занятым ID отклоняется.

В карточке попытки отдельно задают причину изменения, прогноз, окружение, исход и решение. Измеренные `pass`, `fail` и `inconclusive` требуют наблюдения и свидетельства. Для `not_run` наблюдение равно `null`. События SIM используют обычные объекты, контрольные суммы и блокировку записи Continuous Memory.

## Рабочий контекст

Обычная установка сама не читает историю. Команда `context` возвращает только правило из отдельно утверждённого пользователем реестра для точного сочетания модели, харнесса, проекта и версии. Без соответствующей записи результат — `{"rules":[]}`. Экспериментальные решения, включая успешные, остаются в журнале.

```powershell
node tools/ddh.mjs sim --project ./example context --model model-a --harness work --project-name sample --version 6.0.0 --approved-rules ./approved.json
```

Формат внешнего реестра:

```json
{
  "schema_version": "ddh-sim-approved-rules/1",
  "rules": [{
    "problem_id": "SIM-001",
    "rule": "Применять отмену только к задаче, названной в источнике.",
    "environment": {"model": "model-a", "harness": "work", "project": "sample", "version": "6.0.0"}
  }]
}
```

Владелец выбирает этот файл явно. Пример задаёт форму данных. Сам SIM не устанавливает правила, не изменяет настройки и не предоставляет полномочий.
