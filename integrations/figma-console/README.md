# Figma Console MCP

Подключаемый исполнитель Figma, версия 1.46.0, upstream commit 5ef4df3791606b8e1f877557ec0dde4796250b44. Шаблоны входят в отдельные пакеты DDH. Проектная установка DDH добавляет руководство к навыку дизайна.

Для Codex используйте настройки из codex.toml. Для DSH добавьте overlay из dsh.yml в выбранный профиль через его обычный способ композиции. Перед запуском задайте FIGMA_ACCESS_TOKEN в окружении процесса харнесса. Шаблоны ссылаются на переменную. Значение токена в сборке не хранится.

Для локального режима нужен Figma Desktop и запущенный Desktop Bridge в целевом файле. MCP-сервер приносит Bridge в ~/.figma-console-mcp/plugin/. При обновлении сверяйте совместимость Bridge и сервера. Инструмент навигации выбирает уже подключённый файл.

Поля DSH command, args, env и toolCallTimeoutMs проверены по установленному клиенту 0.2.0-rc.2. Поля Codex сверены с upstream setup. Публикация 1.46.0 и dist.integrity проверены через npm view, значение сохранено в integration.json. Сам запуск npx, авторизация и связь с Figma требуют отдельной проверки окружения. В Windows может понадобиться полный путь к поддерживаемому launcher.

После подключения вызовите статус провайдера и проверьте файл. Прочитайте узлы, токены и компоненты. Для разрешённой правки зафиксируйте цель, измените её и проверьте результат повторным чтением и изображением. При тайм-ауте или ошибке ответа после записи сначала прочитайте состояние. Повторяйте только подтверждённо невыполненную операцию.
