# Исправление версии report_run

В исходной ревизии DDH `32e09c392eec4b5125fa1e67af3cff2baa7c0437` корневой `contract_version`, `catalog_version` и версия модуля равны `0.3.0`. При этом два поля `$defs.report_run.properties` оставались `const: "0.2"`: `metric_catalog_version` и `data_contract_version`.

Из-за этого корректная запись нового отчёта с фактическими версиями 0.3.0 не проходила структурную проверку, а ошибочная маркировка 0.2 проходила. Изменены только эти две константы на фактические корневые версии **0.3.0**. Формулы, ID метрик, методология, значения и история источников не изменены. Старый контракт остаётся в истории Git.

Регрессионный тест `test_new_report_versions_pass_and_old_each_fail` использует синтетический report_run: оба правильных значения принимаются, подмена каждого значения на 0.2 отдельно отклоняется. Успех этого теста проверяет структуру и версии, а не готовность отчёта к публикации.
