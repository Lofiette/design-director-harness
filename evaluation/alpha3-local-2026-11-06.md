# Локальная проверка DDH 5.0 alpha 3

6 ноября 2026 года. Версия 5.0.0-alpha.3.

## Результат

22 автоматических теста прошли. Проверены сохранность пакетов, обновление проектной установки, состояние ожидаемого ответа или ревью в чекпоинте и восстановление после остановки процесса.

| Проверка | Наблюдаемый результат |
|---|---|
| Публикация журнала обновления | Сначала записывается и синхронизируется временный файл, затем выполняется rename |
| Остановка до публикации журнала | Убирается только временный журнал из той же транзакции и её устаревшая блокировка |
| Остановка после журнала, навыка, AGENTS.md или receipt | repair-install восстанавливает прежние байты |
| Остановка после фиксации завершения | Сохраняются новые файлы, выполняется очистка метаданных |
| Пользовательская правка во время прерывания | Восстановление отказывается перезаписывать отличающиеся байты |
| Активный установщик | Его блокировка сохраняется, восстановление отказывается продолжать |
| Удерживаемая блокировка восстановления | Вторая попытка и новая установка отказываются продолжать, целевые файлы не меняются |
| Журнал другого проекта, повторные или посторонние пути | Отказ до восстановления файлов |
| Остановка самого восстановления во время записи | Журнал и блокировка восстановления сохраняются для ручной сверки |
| Открытый вопрос или ревью | checkpoint/resume сохраняют pending и возвращают waiting_for_user или waiting_for_review |

Прежние чекпоинты без pending поддерживаются. Исполнение внешних действий по возвращённому состоянию остаётся ответственностью вызывающего агента. Установщик проверен на остановки процессов и взаимодействие собственных команд. Потеря питания и противодействие постороннему процессу, подменяющему каталоги между проверками, не исследовались.

## Пакеты и интеграция

- Codex CLI принял 5.0.0-alpha.3 в отдельном временном профиле. Экспорт содержит 18 файлов, включая шаблоны дополнительной интеграции.
- Копия настоящей проектной установки alpha 2 обновилась до alpha 3. Журнал завершённой транзакции был убран.
- Провайдер DSH 0.2.0-rc.2 обнаружил и загрузил пять навыков из обоих вариантов размещения. Максимальный объём после обёртки составил 4143 символа.
- Codex разобрал шаблон Figma Console через mcp get. DSH принял его конфигурационные поля через установленную схему Config, с тестовым значением окружения.
- Figma Console MCP закреплён на 1.46.0. Версия и dist.integrity ранее подтверждены npm view. Исходный commit, лицензия и integrity сохранены в реестре источников и integration.json.

Сервер Figma Console, настоящий токен, Desktop Bridge и изменения документа Figma в этих проверках не запускались. Поведенческая проверка новых переходов в моделях также остаётся отдельным этапом. Предыдущая живая проверка alpha 2 относится к той версии.

## Независимая проверка

Два агента выполнили проверки только на чтение. Ревью восстановления указало на необходимость атомарной публикации начального журнала и принудительного пересечения команд в тесте. Оба изменения внесены, новые тесты прошли. Ревью Figma сверило минимальные конфигурации с первоисточниками и подтвердило необходимость чтения состояния после ошибки записи перед повтором.
