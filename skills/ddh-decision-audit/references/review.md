# Decision review

## Local and reversible

Record the rollback command and known starting state. Check what could be wrong about the target, what evidence would favor the runner-up, and what observation would show that the result failed. Resolve each material issue before the edit. Apply the focused edit and observe the result. Name the runner-up in the decision record.

## Independent challenge

Give the reviewer the authorized read scope, candidate options, known evidence, and expected response. Ask for a ranking, fit and evidence scores, a refuting probe, and the safety or verification issue most likely to change the decision. Keep the reviewer's work read-only unless the user has authorized more. Use fresh context where the host offers it. The main agent integrates the result and owns the final decision.

A failed probe reopens the decision. Use an agreed retry budget or stop after two repeated failures of the same class to diagnose the cause.
